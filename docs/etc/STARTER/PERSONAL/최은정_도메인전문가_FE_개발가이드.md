1. **도메인 업무 먼저**: 02 3장 Q1~Q12를 PM과 정리(특히 Q2 F-CUS-03 위치, Q8 시나리오 B 범위 → `결정` 이슈 여부). D-19 화면 세부 상태 확인(C05).

## 7. 구현 정책·주의

- 상태(미확인/여유/임박/도래)는 서버 값 그대로. "정상·불량" 같은 표현 금지(09 S-07).
- 목록 연락처는 P0-핵심에서 전체 번호(마스킹은 P0-나머지 F-CUS-07 — **만들지 않음**), 상세도 전체 번호(D-40).
- S-08: 담당 선택 칸 없음, EXTERNAL·DECLINE·점검 결과 입력 없음(P0-나머지).
- S-04: 미동의 고객 제외, 미확인은 대상 아님, "예약 있음" 표시.
- 다른 정비소 id → 404 화면 처리, 403·401 공통 처리는 `client.ts`.
